Optional local activity context

When enabled, eïlo checks which app is in front locally. It can use a Chrome study site's origin and page title, or a simple signal that activity details are not shared. Selected samples may be sent to Luna through your Codex subscription and saved in your Hermes conversation. Unshared activity is never evidence that you are distracted or off your goal.

Chrome withholds unapproved sites' URLs and titles from this extension. On approved sites, Chrome may provide the full URL locally; the extension removes paths, query text and fragments before anything leaves it. It does not read page bodies, browser history, screenshots, keystrokes or the clipboard.

Approved sites: leetcode.com, neetcode.io, docs.python.org. This is a privacy permission, not a productivity rating.

For study-site details, open eïlo in Chrome and follow the extension setup instructions. Without it, only the coarse activity signal is available. Chrome's site grants have broader potential capabilities; the supplied extension only reads the active tab's permitted metadata.

Collection runs only while this enabled page stays open. Pause, Turn off or closing the page stops requests. If the closing signal is lost, collection stops automatically within 9 seconds. Reloading does not enable it again.
