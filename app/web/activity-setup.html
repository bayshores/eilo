Optional Chrome study-site context

eïlo works with conversation and a coarse activity signal without an extension. This local extension adds the permitted origin and page title for your active Chrome tab. Opening this guide does not install it or grant access.

  1. In Chrome, open chrome://extensions. Turn on Developer mode if you choose to install this local, unpacked extension.
  2. Choose Load unpacked and select activity/extension (inside your eïlo checkout).
  3. Open the eïlo extension's popup. Select the study sites you want to share and choose Grant selected sites. The available sites are LeetCode, NeetCode and Python documentation.
  4. Open http://127.0.0.1:8765/ in Chrome. Review Optional local activity context and choose Enable activity context. The installed extension is detected automatically.

The extension reads only the active tab of the focused Chrome window, on explicitly granted study sites, while the enabled eïlo page requests a fresh sample. Chrome withholds unapproved sites' URLs and titles. Paths, queries and fragments from approved URLs are removed locally before delivery. Selected observations may be sent to Luna and saved with your Hermes conversation.

Chrome's host grants can support broader capabilities than these reads. This extension's code does not change tabs or pages and has no content scripts, browser-history, cookies, screenshot or keystroke collection.

To stop: use Pause or Turn off in eïlo, close its page, or revoke selected sites in the extension popup. You can also remove the extension through Chrome's extensions page. It does not run an independent collection loop.
